# tech1k.com

My personal website, <https://tech1k.com>. A single page with a short bio, my contact info and PGP key, and links to my other projects.

It's plain HTML and CSS, hosted on Cloudflare Pages. No JavaScript, no build step. The Inter font is a self-hosted subset and the icons are inline Font Awesome Free.
